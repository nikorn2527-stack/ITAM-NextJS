  5007→   - Auth: `requireAuth(req, 'DEVICE_EDIT')`.
  5008→   - Body: { type, quantity, reason?, relatedAssetNo?, cost?, vendor?, remark? }.
  5009→   - Logic wrapped in `db.$transaction` for atomicity:
  5010→     1. Fetch stock item (404 if missing, 403 if site forbidden).
  5011→     2. Compute new balance: IN → +quantity (reject if qty ≤ 0); OUT → -quantity (reject if would go negative); ADJUST → set to absolute quantity (reject if qty < 0).
  5012→     3. Create StockTransaction with balanceAfter = new balance, txnId = `STX-${Date.now()}`, txnDate = now ISO, performedBy = user.email.
  5013→     4. Update StockItem.quantity = new balance.
  5014→   - Audit log: action='STOCK_TRANSACTION', summary `รับเข้า/เบิกออก/ปรับปรุงสต็อก "${name}" จำนวน ... (คงเหลือ ${balanceAfter})`, detail carries type/quantity/balanceAfter/reason/relatedAssetNo.
  5015→   - Response: `{ transaction, item }` (status 201).
