   231→   231→## 4. ระบบสิทธิ์และความปลอดภัย (RBAC)
   232→   232→
   233→   233→### 5 Roles
   234→   234→| Role | ชื่อแสดง | สิทธิ์หลัก |
   235→   235→|------|----------|-----------|
   236→   236→| `superadmin` | ผู้ดูแลสูงสุด | ทุกอย่าง + จัดการ Admin คนอื่น |
   237→   237→| `admin` | ผู้ดูแลระบบ | ทุกอย่าง ยกเว้นจัดการ Super Admin |
   238→   238→| `editor` | เจ้าหน้าที่จัดการข้อมูล | ดู/เพิ่ม/แก้ไข/ย้าย/จดมิเตอร์/Export |
   239→   239→| `meter` | ผู้จดมิเตอร์ | ดูอุปกรณ์ + จดมิเตอร์ + Print |
   240→   240→| `viewer` | ผู้ดูรายงาน | ดูข้อมูล + Dashboard + Print |
   241→   241→
   242→   242→### Permissions (12 ตัว)
   243→   243→```
   244→   244→VIEW_DASHBOARD, VIEW_DEVICES, VIEW_ANALYTICS,
   245→   245→METER_WRITE, DEVICE_EDIT, DEVICE_DELETE,
   246→   246→DEVICE_TRANSFER, LIFECYCLE_EDIT, MASTER_DATA_EDIT,
   247→   247→EXPORT_PRINT, PRINT, ADMIN
   248→   248→```
   249→   249→
   250→   250→### วิธี Login (2 ช่องทาง)
   251→   251→1. **Google Session** — Login ผ่าน Google Account (ถ้า deploy แบบ USER_DEPLOYING)
   252→   252→2. **Username/Password** — Login ผ่านฟอร์ม (SHA-256 + salt hash)
   253→   253→
   254→   254→### ความปลอดภัย
   255→   255→- ✅ Password hashing: SHA-256 + salt (per-user salt)
   256→   256→- ✅ Rate limiting: 5 ครั้งผิด → lockout 5 นาที
   257→   257→- ✅ Auth token: UUID + CacheService (TTL 6 ชั่วโมง)
   258→   258→- ✅ Row-level security: `Allowed_Sites` จำกัดการเห็นข้อมูลตาม Site
   259→   259→- ✅ "Last admin" protection: กันปิด admin คนสุดท้าย
   260→   260→- ✅ Audit Log: บันทึกทุกการกระทำสำคัญ
   261→   261→
   262→   262→### Site-based Row-level Security
   263→   263→ครอบคลุม:
   264→   264→- รายการอุปกรณ์ (All_Devices)
   265→   265→- ประวัติการย้าย (Location_History)
   266→   266→- ประวัติมิเตอร์ (Meter_Readings)
   267→   267→- ตัวเลือก Dropdown (Master_Data)
   268→   268→- ผลลัพธ์ Paper Analytics และ Dashboard

   362→   362→### 6.2 Multi-template Library
   363→   363→
   364→   364→#### โครงสร้าง JSON Template
   365→   365→```javascript
   366→   366→{
   367→   367→  id: 'default',              // unique id ('default' ลบไม่ได้)
   368→   368→  name: 'เทมเพลตเริ่มต้น',     // ชื่อที่แสดง
   369→   369→  isDefault: true,            // ลบไม่ได้
   370→   370→  canvas: {
   371→   371→    width: 75.2,              // ความกว้าง mm
   372→   372→    height: 36,               // ความสูง mm
   373→   373→    unit: 'mm'
   374→   374→  },
   375→   375→  overflow: 'clip',           // 'clip' (ตัด) | 'visible' (เกินขอบ)
   376→   376→  elements: [
   377→   377→    {
   378→   378→      id: 'logo',
   379→   379→      type: 'text' | 'image' | 'qr' | 'rect',
   380→   380→      x: 1, y: 1,             // ตำแหน่ง (mm)
   381→   381→      width: 11, height: 11,  // ขนาด (mm)
   382→   382→      opacity: 1,             // 0-1 (ความโปร่งใส)
   383→   383→      zIndex: 1,              // ลำดับชั้น
   384→   384→      rotation: 0,            // องศา (optional)
   385→   385→      // type-specific:
   386→   386→      // text: fontSize, fontWeight, color, align, content, border, background
   387→   387→      // image: source, objectFit
   388→   388→      // qr: source
   389→   389→      // rect: background, border
   390→   390→    }
   391→   391→    // ... 17 elements ใน default
   392→   392→  ]
   393→   393→}
   394→   394→```

   396→   396→#### การจัดการ Library (UI ใน Settings → 🎨 สติกเกอร์)
   397→   397→- **📋 Template List** — แสดงทุก template พร้อม badges:
   398→   398→  - ⭐ = template ที่ใช้งานอยู่ (active)
   399→   399→  - ✏️ = template ที่กำลังแก้ไข
   400→   400→  - 📄 = template ปกติ
   401→   401→  - `[เริ่มต้น]` = default template (ลบไม่ได้)
   402→   402→  - `[ใช้อยู่]` = active template
   403→   403→- **➕ สร้างเทมเพลตใหม่** — เริ่มจาก default
   404→   404→- **📋 ทำสำเนา** — duplicate template ที่มีอยู่
   405→   405→- **⭐ ตั้งเป็นที่ใช้งาน** — set as active
   406→   406→- **🗑️ ลบ** — ลบ template (ยกเว้น default + active)
   407→   407→- **✏️ แก้ไข** — เปิดใน editor

   557→   557→   - updateAppSettings (เมื่อ toggle flag)
   558→   558→3. Client: `stickerSettingsNeedsReload()` ตรวจทุกครั้งที่ print
   559→   559→   - ถ้า > 60 วินาทีหลัง print ล่าสุด → reload
   560→   560→   - ถ้า version เปลี่ยน → reload
   561→   561→4. Manual refresh: ปุ่ม "🔄 รีเฟรชการตั้งค่า" ใน bulk-sticker-bar
   562→   562→
   563→   563→### 6.8 Rollback (3 ระดับ)
   564→   564→- **Level 1**: ปิด toggle "เปิดใช้งานเทมเพลต" → ใช้ default template
   565→   565→- **Level 2**: ลบ template ที่ไม่ใช้ใน library
   566→   566→- **Level 3**: git revert commit

   692→   692→## 9. Performance และ Cache
   693→   693→
   694→   694→### 3 ชั้น Cache
   695→   695→
   696→   696→#### ชั้นที่ 1: Request Cache (`_rc`)
   697→   697→- ใช้ตลอดอายุ 1 request (doGet/doPost)
   698→   698→- ป้องกันอ่าน Sheet ซ้ำใน request เดียวกัน
   699→   699→- `rcClear()` เรียกตอนเริ่ม doGet
   700→   700→
   701→   701→```javascript
   702→   702→var _rc = {};
   703→   703→function rcLazy(key, fn) {
   704→   704→  return _rc.hasOwnProperty(key) ? _rc[key] : (_rc[key] = fn());
   705→   705→}
   706→   706→```
   707→   707→
   708→   708→#### ชั้นที่ 2: Script Cache (CacheService)
   709→   709→- TTL ต่างกันตามประเภท:
   710→   710→  - Dashboard: 180 วินาที
   711→   711→  - App Settings: 300 วินาที
   712→   712→  - Auth: 60 วินาที
   713→   713→  - Site Attributes: 300 วินาที
   714→   714→
   715→   715→#### ชั้นที่ 3: Client Cache (browser)
   716→   716→- `state.stickerSettingsLoaded` — โหลด settings ครั้งเดียว
   717→   717→- `state.activeStickerTemplate` — เก็บ template ที่โหลดแล้ว
   718→   718→- `stickerTemplateVersion` — version stamp สำหรับ invalidate
   719→   719→- Cache window: 60 วินาที (performance)
   720→   720→
   721→   721→### การ Optimize
   722→   722→- **Batch operations** — `batchUpdateRow()` ทำ 1 API call ต่อหลายคอลัมน์
   723→   723→- **LockService** — กัน concurrent write conflict ตอน add/transfer device
   724→   724→- **Header alias mapping** — รองรับชื่อคอลัมน์ไทย/อังกฤษ 10+ รูปแบบ
   725→   725→
   726→   726→### Quota ที่ต้องระวัง
   727→   727→- `UrlFetchApp`: 20,000 calls/day (QR codes ผ่าน quickchart.io)
   728→   728→- `MailApp`: 100 emails/day
   729→   729→- Execution timeout: 6 นาทีต่อ request

   916→   916→### ปัญหาทั่วไป

   918→   918→#### สติกเกอร์พิมพ์ไม่ตรงกับ Settings ล่าสุด
   919→   919→**สาเหตุ:** Client cache ค้าง
   920→   920→**วิธีแก้:**
   921→   921→1. กดปุ่ม "🔄 รีเฟรชการตั้งค่า" ใน bulk-sticker-bar
   922→   922→2. หรือรีเฟรชหน้าเว็บ (F5)
   923→   923→3. หรือรอ 60 วินาที (cache auto-expire)
   924→   924→
   925→   925→#### ชื่อ template พิมพ์ไม่ติด
   926→   926→**สาเหตุ:** `updateTemplateEditHeader()` เขียนทับ input
   927→   927→**วิธีแก้:** อัปเดตเป็นเวอร์ชันล่าสุด (commit `8303206`)
   928→   928→
   929→   929→#### Bulk print ขนาดไม่ตรง
   930→   930→**สาเหตุ:** `75.2mm` hardcoded ใน CSS + JS
   931→   931→**วิธีแก้:** อัปเดตเป็นเวอร์ชันล่าสุด (commit `9e24d0b`)
   932→   932→
   933→   933→#### ข้อความ 3 บรรทัดหัวสติกเกอร์หาย
   934→   934→**สาเหตุ:** fallback values ว่าง
   935→   935→**วิธีแก้:** อัปเดตเป็นเวอร์ชันล่าสุด (commit `245043f`)
   936→   936→
   937→   937→#### Logo ไม่แสดง
   938→   938→**สาเหตุ:** หลายสาเหตุ:
   939→   939→1. `stickerLogoUrl` ว่าง → ตรวจสอบใน App_Settings
   940→   940→2. Logo URL ไม่ถูกต้อง → ตรวจสอบ URL
   941→   941→3. data:image/... ใหญ่เกิน 50,000 ตัวอักษร → ใช้ chunking
   942→   942→4. Browser block รูปจาก external domain → ใช้ data URL แทน
   943→   943→
   944→   944→#### Login ไม่ได้
   945→   945→**สาเหตุ:** Rate limit หรือ password ผิด
   946→   946→**วิธีแก้:**
   947→   947→1. รอ 5 นาที (lockout หมดอายุ)
   948→   948→2. ตรวจสอบ User_Permissions sheet ว่า Active = TRUE
   949→   949→3. ตรวจสอบ PasswordHash + PasswordSalt
   950→   950→
   951→   951→#### Sheet ไม่พบ
   952→   952→**สาเหตุ:** ชื่อ sheet ผิด
   953→   953→**วิธีแก้:** ตรวจสอบชื่อ sheet ตรงกับ CONFIG ใน Code.gs
