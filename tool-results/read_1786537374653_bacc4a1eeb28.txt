   232→## ความเสี่ยงที่เหลือ
   233→
   234→1. **Print layout บางเครื่องไม่รองรับ CSS grid ใน @media print** — ถ้าเจอต้องเปลี่ยนเป็น flexbox ใน css.html `.bulk-sticker-mode`
   235→2. **QuickChart QR API อาจ rate limit** เมื่อ print 60 เครื่องพร้อมกัน — แนะนำ stagger loading ในอนาคต
   236→3. **`@page size: A4` override** อาจไม่ทำงานบาง browser — ผู้ใช้อาจต้องเลือก "A4" ใน print dialog เอง
   237→4. **Apps Script quota** — `UrlFetchApp` มีขีดจำกัด 20,000 calls/day; QR 60 รูปต่อการ print 1 ครั้ง = ไม่มีปัญหา
   238→5. **Browser pop-up blocker** — `window.print()` อาจถูก block ในบาง browser ถ้าไม่ใช่ user gesture (แต่ในที่นี้คลิกปุ่ม = user gesture, ปลอดภัย)
